# AfroGenomics — Clinical Genomics Computing

Clinical-genomics-focused React + TypeScript + Vite website.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production output is `dist/`.

## Deploy on Render

Use a **Static Site**:

- Branch: `main`
- Build command: `npm run build`
- Publish directory: `dist`
- Start command: leave empty

## Deploy on Netlify

The included `netlify.toml` and `public/_redirects` configure Vite SPA routing.


## Why Africa visual
The Why Africa section uses the supplied clinical-genomics image as a local asset at `public/africa-clinical-genomics.png`.
